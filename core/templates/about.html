vCommunity Observability v{{ version }}

An open-source framework that collects data from vCenter and VCF Operations, stores it locally in SQLite, and serves it as dashboards styled after VCF Operations and as REST endpoints for VCF Operations Management Pack Builder. It works offline, so it suits dark sites. Collector modules are plug-ins written in Python or PowerShell.
