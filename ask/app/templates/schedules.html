Scheduled prompts

A prompt Ask answers on a schedule and emails to you. Each run is answered exactly like a chat and saved as a chat (Scheduled: name · date), so you can open it and ask follow-up questions. The email holds the answer, its sources with their URLs, an Open in Ask link and the HTML report when the answer made one. Email goes through the mail server set up in vCommunity Observability (Log alerts → Notifications).
