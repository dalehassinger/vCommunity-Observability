vCommunity Ask v{{ version }}

A chat prompt answered by your local Ollama, only from the knowledge sources you choose: markdown in a Git repository, the posts of a web site or blog, PDF documents (scanned ones too, with OCR), or spreadsheets such as RVTools and the DBH Insights export. Nothing leaves your machine, unless you tick Web search (Ollama): then your knowledge sources are still searched first, and the model searches the web (Ollama's cloud web search) only when they don't answer or the question needs current information. Web results are cited like any other source. It is the second container of vCommunity-Observability, and the full project README is below.
