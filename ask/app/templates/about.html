vCommunity Ask v{{ version }}

A chat prompt answered by your local Ollama or LM Studio (turn either one on or off on the Settings page; both can be on, and the model menu lists each one's models), only from the knowledge sources you choose: markdown in a Git repository, the posts of a web site or blog, PDF documents (scanned ones too, with OCR), or spreadsheets such as RVTools and the DBH Insights export. Nothing leaves your machine, unless you tick Web search (Ollama) or Web search (Brave): then your knowledge sources are still searched first, and the model searches the web (Ollama's or Brave's cloud search) only when they don't answer or the question needs current information. Web results are cited like any other source. Ask can also call the tools of your own MCP servers, such as the draw.io MCP container that draws diagrams, which open offline in the local draw.io editor container or in draw.io Desktop on your Mac and can use your own shape libraries (see MCP servers over HTTP, Your own shape libraries and Writing diagram prompts) and the 39 vCenter, VCF Operations, lab network and Salt tools of the PowerShell MCP server (listed under The tools in Dale's PowerShell MCP server below). The Performance page shows what Ollama and LM Studio have loaded and the CPU and memory they use (see LM Studio below). Any answer can be saved to Apple Notes on your Mac with one click, and scheduled prompts can deliver to Apple Notes too (see Apple Notes). With the Apple Reminders tools a prompt can add items to a list such as Groceries (see Apple Reminders). It is the second container of vCommunity-Observability, and the full project README is below.
