MCP tools

Tools of the MCP servers that run on your Mac (through the Ask host agent) and of the MCP servers Ask reaches over HTTP, such as the draw.io container. Pick Tools: <server> in the chat's Sources menu and the model can call them. Edit the server's script and press Reload tools (or just ask again: a changed script restarts the server by itself).

MCP servers over HTTP
MCP servers Ask calls itself (Streamable HTTP), one per line: name = url. The name is what the Sources chips show (Tools: name). From inside Docker use the container's name, for example drawio = http://drawio-mcp:3001/mcp for the draw.io MCP container, or host.docker.internal for a server on the Mac. A header can follow the URL: name = url | Authorization: Bearer …. Saved with Save below; press Refresh to see the tools.
Which link the answer gives for a diagram from the draw.io MCP server. Either way the tool card has both: Open in draw.io (local web editor) and Open in draw.io Desktop (Ask saves the diagram as a .drawio file and the host agent opens it in the app; without the agent the file is downloaded).

Your own draw.io libraries (*.xml saved from draw.io) in the drawio-libs folder next to docker-compose.yml. Ask tells the model their shape names and puts the real shapes into its diagrams; the web editor opens with them in its sidebar. Files are read again when they change.
The draw.io MCP server answers with links to the public editor (app.diagrams.net). With a local draw.io editor here (the drawio container, jgraph/drawio), Ask points those links at it, so diagrams open without the internet. Use the address your browser opens. Empty = keep the public links.
