Send syslog here

Anything that speaks syslog can send here: ESXi hosts, vCenter, other appliances, switches, your own scripts and apps. Use this computer's address, this-server, port 514. UDP is the usual choice; TCP does not lose messages when the network is busy. Containers in the same docker compose project use vco:5514 instead.

vCommunity Ask (built in)

Ask sends every prompt, the model's thinking, tool calls and a short answer summary as app vcommunity-ask. Turn it on or off, and choose what is sent, on Ask's Settings page under Activity log. See Ask activity

One ESXi host (SSH or the ESXi Shell)

esxcli system syslog config set --loghost='udp://this-server:514'
esxcli network firewall ruleset set --ruleset-id=syslog --enabled=true
esxcli system syslog reload

Every host in vCenter (PowerCLI)

Connect-VIServer -Server <vcenter>
Get-VMHost | Get-AdvancedSetting -Name Syslog.global.logHost |
    Set-AdvancedSetting -Value 'udp://this-server:514' -Confirm:$false
Get-VMHost | Get-VMHostFirewallException -Name 'syslog' | Set-VMHostFirewallException -Enabled:$true

Your own script (PowerShell 7)

function Send-Syslog {
    param([Parameter(Mandatory)][string]$Message, [string]$App = 'my-script', [int]$Severity = 6,
          [string]$Server = 'this-server', [int]$Port = 514, [ValidateSet('tcp', 'udp')][string]$Protocol = 'tcp')
    $ts    = (Get-Date).ToUniversalTime().ToString('yyyy-MM-ddTHH:mm:ss.fffZ')
    $raw   = "<$(8 * 16 + $Severity)>1 $ts $([Environment]::MachineName) $App $PID - - $Message"
    $bytes = [Text.Encoding]::UTF8.GetBytes($raw)
    if ($Protocol -eq 'udp') {
        $udp = [System.Net.Sockets.UdpClient]::new(); [void]$udp.Send($bytes, $bytes.Length, $Server, $Port); $udp.Close(); return
    }
    $tcp = [System.Net.Sockets.TcpClient]::new($Server, $Port)     # fails loudly when nothing listens
    $s   = $tcp.GetStream()
    $len = [Text.Encoding]::ASCII.GetBytes("$($bytes.Length) ")    # octet counting (RFC 6587), like ESXi
    $s.Write($len, 0, $len.Length); $s.Write($bytes, 0, $bytes.Length); $s.Flush(); $tcp.Close()
}
Send-Syslog 'Nightly report finished: 42 VMs checked'
Send-Syslog 'Datastore DS01 is 91% full' -Severity 4               # warning

On the computer that runs the containers, use -Server 127.0.0.1.

Your own script (Python)

import logging, logging.handlers
log = logging.getLogger("my-script")
log.addHandler(logging.handlers.SysLogHandler(address=("this-server", 514)))
log.setLevel(logging.INFO)
log.warning("my-script: datastore DS01 is 91% full")
